# 📝 To-Do List Application

A simple JavaFX-based To-Do List application built to showcase my skills in **Java programming, GUI design, and project structuring**.  
This project demonstrates clean code practices, event-driven programming, and user interface styling in JavaFX.

---

## 🚀 Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Clean and responsive JavaFX GUI
- Lightweight project structure (no external dependencies)

---

## 🛠️ Technologies Used
- **Java** (Core language)
- **JavaFX** (GUI framework)
- **NetBeans IDE** (Project setup and build)

---

## 📂 Project Structure
- `src/` → Source code
- `nbproject/project.properties` → NetBeans project settings
- `nbproject/project.xml` → NetBeans project structure
